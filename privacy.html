隐私政策

VSniff · 生效日期 2026-10-20 · 首页 · English

读取什么

频道主在 Google 授权页面同意后，VSniff 通过 YouTube API 服务（YouTube Data API、YouTube Analytics API、YouTube Reporting API），用只读权限读取这个频道的：

  • 视频列表和视频信息：标题、简介、时长、发布时间等；
  • 统计数据：播放、点赞、评论数、观看时长、观众留存、流量来源、曝光和点击率等。

VSniff 不读取其他用户的个人信息。

怎么用

只用来给频道主看自己视频的效果，不用于广告或其他用途。

存在哪

数据和授权凭据只保存在频道主自己的电脑上，授权凭据存在系统钥匙串里。VSniff 没有服务器，不会把数据传到别处。

分享

不向任何第三方出售、出租或提供这些数据。

删除和撤销授权

频道主可以随时删除本机上的数据。要撤销 VSniff 的访问权限，打开 Google 账号的安全设置页面 https://security.google.com/settings/security/permissions，移除 VSniff。撤销后 VSniff 不能再读取任何数据。

本网站

这几个网页本身不用 Cookie，也不放统计代码。网页由 GitHub Pages 托管。

相关条款

VSniff 使用 YouTube API 服务。使用 VSniff 即表示同意 YouTube 服务条款。Google 如何处理数据，见 Google 隐私权政策。

联系

有问题请在 GitHub 上提 Issue。

变更

本政策有变化时，会更新本页并修改生效日期。

Privacy Policy

VSniff · Effective October 20, 2026 · Home

What VSniff reads

After the channel owner gives consent on Google's authorization page, VSniff uses YouTube API Services (YouTube Data API, YouTube Analytics API and YouTube Reporting API) with read-only access to read, for that channel only:

  • the video list and video details such as title, description, duration and publish time;
  • statistics such as views, likes, comment counts, watch time, audience retention, traffic sources, impressions and click-through rate.

VSniff does not read personal information about other users.

How it is used

Only to show the channel owner how their own videos perform. It is not used for advertising or any other purpose.

Where it is stored

The data and the authorization credentials are stored only on the owner's own computer; the credentials are kept in the system keychain. VSniff has no server and does not send the data anywhere else.

Sharing

The data is not sold, rented or given to any third party.

Deletion and revoking access

The owner can delete the local data at any time. To revoke VSniff's access, open the Google security settings page at https://security.google.com/settings/security/permissions and remove VSniff. After that, VSniff can no longer read any data.

This website

These pages do not use cookies or analytics. They are hosted on GitHub Pages.

Related terms

VSniff uses YouTube API Services. By using VSniff you agree to the YouTube Terms of Service. For how Google handles data, see the Google Privacy Policy.
