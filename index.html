VSniff

读取自己 YouTube 频道数据的个人工具

VSniff 是一个个人工具：频道主用它读取自己 YouTube 频道的数据，看自己发布的视频效果怎么样。

  • 通过 YouTube API 服务读取视频列表和统计数据：播放、点赞、评论数、观看时长、观众留存、流量来源、曝光和点击率等。
  • 只申请只读权限，不会上传、修改或删除频道里的任何内容。
  • 只给频道主自己用，不对外提供服务。
  • 数据只保存在频道主自己的电脑上。

隐私政策 · 使用条款

English

VSniff is a personal tool. The channel owner uses it to read their own YouTube channel's data and see how their published videos perform.

  • It uses YouTube API Services to read the video list and statistics such as views, likes, comment counts, watch time, audience retention, traffic sources, impressions and click-through rate.
  • It requests read-only access. It never uploads, changes or deletes anything on the channel.
  • It is used only by the channel owner and is not offered to anyone else.
  • All data stays on the owner's own computer.
